✅ Rent House — HTML & CSS Only (Flex, Grid, Responsive)
Project goal

To demonstrate the full capabilities of flexbox, grid, and responsive design using only HTML and CSS, with a strong focus on the sidebar and RTL support for right-to-left languages like Persian.
Deliver a clean, maintainable UI that can shine in interviews and portfolio showcases.
🎯 Key objectives

Fully utilize Flexbox and Grid for layout of the sidebar and main content.
Achieve responsive behavior across mobile, tablet, and desktop without JavaScript.
Provide a maintainable structure with CSS variables for easy customization.
✨ What this project provides

Pure HTML/CSS responsive design using Flexbox and CSS Grid
Desktop sidebar and mobile-friendly stacking behavior
Clean, maintainable structure with CSS variables for easy customization
RTL-ready — dir=“rtl” and appropriate CSS considerations
🧰 Technologies and trade-offs

HTML5 + CSS3 only
No JavaScript (to emphasize learning responsive design)
Limitations: no dynamic interactivity (no JS-driven dropdowns or complex animations)
🚀 Getting started

Open index.html in a browser and resize to test responsiveness
Customize colors and spacing via CSS variables in :root
Optional local server:
Python: python3 -m http.server 8000 (from project folder)
Node: any lightweight static server (e.g., live-server)
🗂 Project structure

index.html
styles.css
assets/ (images or icons)
🎨 Layout and responsive strategy

Sidebar uses Flexbox/Grid for navigation and filters
Main content uses Grid for property cards
Breakpoints ensure proper stacking and alignment across mobile, tablet, and desktop
RTL alignment ready for Arabic/English content
♿ Accessibility

Semantic HTML for screen readers
Focus styles for keyboard navigation
✏️ Customization

Adjust colors and sizes via CSS variables in :root
For quick edits, modify styles.css or add more variables to suit your design
🛠 Limitations and trade-offs

No JavaScript means limited interactivity (no dynamic dropdowns or menus)
CSS-only interactivity has limits; consider minimal JS for richer UX if needed
💡 Future improvements

Add CSS-only or minimal JavaScript enhancements for menus, filtering, and subtle animations
Create additional templates for different property blocks and easier customization
Prepare an Arabic version to better align with RTL markets if needed
